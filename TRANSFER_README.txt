FIELDTRACK GITHUB TRANSFER PACKAGE

1. Extract this ZIP in the iPhone Files app or on a computer.
2. Open https://github.com/hunter2026CA/FieldTrack
3. Choose Add file > Upload files.
4. Upload the files inside this extracted folder (not the ZIP itself).
5. Commit message: Import FieldTrack v7 prototype and GPS tests
6. Commit directly to main for this initial import.

Do not upload personal hunting coordinates, credentials, API keys, or passwords.

This import does not deploy the app or enable multi-hunter live location sharing.
